API de Integração

Permita que o sistema da sua empresa consulte máquinas, unidades e chamados do AtivoFix — e abra chamados automaticamente. Cada empresa tem a própria chave de API: ela só enxerga e age dentro da empresa dela. Nada de outras empresas é acessível.

📡 Como o sistema da empresa consome

Todas as requisições enviam a chave no header X-API-KEY. Exemplo real em 3 linguagens:

# curl (teste rápido) curl https://ativofix.com.br/api/v1/ping \ -H "X-API-KEY: afk_sua_chave_aqui" # Python (sistema da empresa) import requests r = requests.get("https://ativofix.com.br/api/v1/computers", headers={"X-API-KEY": "afk_sua_chave_aqui"}) dados = r.json() # {"total": 42, "computers": [...]} # JavaScript / Node const r = await fetch("https://ativofix.com.br/api/v1/tickets?status=open", { headers: { "X-API-KEY": "afk_sua_chave_aqui" } }); const chamados = await r.json();

📚 Endpoints

GET/api/v1/ping

Confirma que a chave é válida. Resposta: {"ok": true, "tenant": "AHBB"}

GET/api/v1/computers

Máquinas da empresa, com unidade/local e status online (reportou nos últimos 3 min).

ParâmetroValoresDescrição
onlinetrue / falseFiltrar por status
payloadtrueIncluir hardware completo (CPU, RAM, discos)
GET/api/v1/units

Unidades da empresa com contagem de locais e máquinas.

GET/api/v1/locations?unit_id=N

Locais, opcionalmente filtrados por unidade.

GET/api/v1/tickets

Chamados da empresa, mais recentes primeiro.

ParâmetroExemploDescrição
statusopen, in_progress, resolved, closedStatus do chamado
from / to2026-09-01Período de criação
limit / offset100 / 0Paginação (máx 500)
POST/api/v1/tickets

Abre um chamado no AtivoFix pelo sistema da empresa. O chamado cai na unidade certa e notifica o T.I. dela.

POST /api/v1/tickets X-API-KEY: afk_... { "title": "Impressora nao imprime", "description": "Triagem - impressora HP nao responde", "priority": "high", // low|medium|high|critical "unit_name": "HSL Garca", // ou unit_id: 5 "location_name": "triagem", // opcional (ou location_id) "tag_evo": "EVO-XXXXXX", // opcional: vincula a maquina "cpf": "000.000.000-00" // opcional }

Resposta: 201 {"ok": true, "ticket_id": 123} — valida unidade/local como pertencentes à empresa da chave (404 caso contrário).

🛡️ Segurança

IsolamentoA chave trava a consulta na empresa dela — impossível acessar dados de outras empresas
ArmazenamentoSó o hash da chave fica no banco; a chave completa aparece uma única vez, na criação
ComparaçãoTempo constante (imune a timing attack)
HTTPSTudo via TLS (Let's Encrypt) — a chave nunca trafega em texto plano
RevozocaçãoDesative ou exclua a chave a qualquer momento — efeito imediato
